# Optional Landing atmosphere measurement

Use an isolated credential-free loopback-only environment with locked dependencies and installed Chromium. From the repository root: `node node_modules/@playwright/test/cli.js test --config tests/measurement/playwright.config.ts`. This starts the real Next development server (no production or provider access); do not load a real account or use a configured environment. The test does not alter existing CI configurations. The image test uses actual Next image-optimizer responses, records encoded response-body bytes and computes RGB PSNR against the source resized to the actual derivative dimensions. 38 dB limits RGB RMS error to about 3.21/255; this is an engineering gate, not a substitute for visual approval. The geometry test uses the real Landing component and replaces only the two CSS image variables with the original URLs; external photographs are identically stubbed in both states. It checks computed crop, gradient, attachment and locked arc geometry, not subjective full-page fidelity. All five candidates must save bytes and meet the threshold. Report the exact SHA, log rows and failures; never merge on the basis of a skipped measurement.
