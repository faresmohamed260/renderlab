## Behavior that must not change

- Only FIBO image create/edit is enabled for new jobs. Qwen/FLUX/LTX and `preparing` compatibility paths stay readable, but retired models must not become newly dispatchable. Preserve model/payload validation, owner-scoped inputs, PNG masks, auto-VGL and source slots.
- Durable outbox dispatch acceptance, stable attempt identities, wake-after-acceptance, ambiguous/unconfirmed provider send handling, cancellation claims, reconcile tokens and status-CAS all remain in the same order. Preserve worker retries/grace (15-minute missing worker/dispatch; two-hour provider uncertainty), 202/404/409/410/422/503 outcomes and exact `FIBO_PROCESS_EXITED` failure mapping.
- Preserve all **eight** Unit 4 statuses, their **64** state-pair judgments, terminal immutability, and owner-return/replay behavior. Preserve **0031 atomic terminalization** for terminal PATCHes, distinguishing an absent RPC (fallback to old CAS) from an applied/conflicted RPC result. Never change the fallback, role/grant, schema or reservation release semantics.
- Keep deterministic R2 object/asset IDs and output-index uniqueness, thumbnail bytes, sidecar-before-`persisting` order, fault injection checkpoints, media provenance, diagnostics and user-visible error codes/messages. No changes to DB/R2 call order, timeout handling or error redaction.
- Every existing import of `@/server/generation/native-generation` or its relative equivalent continues to work through **explicit re-exports**. Avoid cycles: extracted modules import one another directly, never through the facade. Moving an implementation body must be verbatim (only imports/exports change).

## Exact order of independent small PRs

1. **Design/docs PR** (this document, docs index and governance registry). Merge on green after release-window clearance; no runtime diff.
2. **Characterization test PR first, if needed:** before moving the first row writer, lock down public export compatibility and `patchJob` applied/terminal/lost-CAS/absent-RPC fallback with existing injected fake Supabase. Extend Unit 5 event-order characterization only if its existing 23 cases do not cover a moved boundary. No code moves in this PR.
3. **Job-store move:** transfer the row types, `getJobRow`, `toGenerationJob`, `patchJob`, `patchJobRow` verbatim; old import path explicitly re-exports. Preserve the atomic RPC/fallback exactly.
4. **Inputs move:** owner-scoped sources, mask bytes and persisted request reconstruction. Characterize owner denial, invalid mask and re-dispatch guards before the move where necessary.
5. **Legacy workflow move:** catalog/workflow selector and non-FIBO form prep with all old model guards unchanged.
6. **Transport move:** FIBO gateway dispatch, wake, sidecar, poster and error decoding; verify exact wire payload, auth and ambiguous status order.
7. **Persistence move:** R2/image thumbnail, media insert, recovery and finalization; verify fail-after-primary-write and duplicate callback convergence.
8. **Orchestration move:** remaining job lifecycle and failure/reassignment functions; collapse original file to stable explicit exports; no call-site rewrites.
9. **Later, separate authorization and release:** integrate #569's **unwired legacy lifecycle FIBO adapter** only after a true **provider-only** FIBO transport seam exists. Shadow-conformance with an injected provider and a fake second adapter first; never dual-admit, dual-submit or double-settle, and never enable retired or second providers by the extraction.

Each PR is created against refreshed `main` after the previous accepted merge. Rebase if another worker updates `main` and **rerun every required check on the changed head**. Do not merge an intermediate failing state or combine extraction with logic cleanups, schema/API/provider edits, deployment, secrets or production calls.
