# FIBO beta correctness incidents, November 22–23, 2026

| Incident | Detection | Correction and release |
| --- | --- | --- |
| Stale Modal proxy token after the Vercel account migration | The production status request got an upstream HTTP 401 after a Modal call had been accepted. The app preserved the unconfirmed outcome as `running`. The investigation checked the gateway identity and current proxy-token pair. | The authorized credential correction redeployed the exact app source `decd2f6b7a2a640806649c123b2ea5bb9e552aa0` to `dpl_EU4SYENB2CwJoxk6PfSjZHqewvbb`. [Release record #525](https://github.com/faresmohamed260/renderlab/pull/525) and [legacy token revocation #531](https://github.com/faresmohamed260/renderlab/pull/531) record the changes. |
| Production beta access and mask flags dropped | The migration comparison found both Vercel Production variable names missing. The closed-beta access gate was ineffective and masked edits were unavailable. | Both flags were restored in `dpl_FoWum6qkiEx9f2TEDHa36926zVZ5` at `f1d04f889c3d810876e30365a49658932853b381`. The verification found private APIs returned 401 for non-admitted users and the saved masked edit changed zero pixels outside the mask. [Release record and names-only preflight #533](https://github.com/faresmohamed260/renderlab/pull/533). |
| Submit hit the 10-second Vercel limit | A submission could time out while waiting for the Modal dispatcher wake, although the job and outbox had already committed. The production project ran Hobby with Fluid Compute off. | The app returns the queued response after durable acceptance and reservation binding, then wakes dispatch after the response. The submit route declares 60 seconds. `dpl_DRDegFSonnfW88rhdHhmPJoTsQq5` at `2db59d904bd02b8fc6e6d4690d4417f4ba55d176` shipped the fix. [Fix #526](https://github.com/faresmohamed260/renderlab/pull/526) and [release record #527](https://github.com/faresmohamed260/renderlab/pull/527). |
| A finished render stayed unsettled without a polling browser | The protected status path could finalize, but a closed tab left the app job `running`, with zero Library assets and the slot occupied even after Modal finished. | The owner-scoped Create, Library, Activity and occupied-submit recovery paths reuse the existing claim and persistence flow. `dpl_79zdxuQYSkUpFxVBzS29Rjn8aD6L` at `4551551f85d0b75ad1fb1043a6cbe1dc197cf567` shipped [fix #534](https://github.com/faresmohamed260/renderlab/pull/534). [One Library load](https://github.com/faresmohamed260/renderlab/actions/runs/45099617648) moved the single unpolled fixture to `succeeded`, saved one asset and released the reservation. [Release record #535](https://github.com/faresmohamed260/renderlab/pull/535). |

Production publishes separate evidence for the [ADR-005 process-exit path](ADR005_PROCESS_EXIT_RECOVERY_VERIFIED_2026-11-22.md).
