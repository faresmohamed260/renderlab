## Reusable acceptance harness

Run `npx --no-install playwright test --config tests/components/playwright.config.ts create-overflow-acceptance.spec.ts` with the existing pinned dependencies and Chromium. The same suite runs in the existing optional mounted-component workflow. The fixture root mirrors the actual production body/atmosphere, imports the real PreviewNavigationShell and mounts the real Create workspace inside the app main; all server/account/history/capability I/O is synthetic and credential-free. Other mounted tests keep their original fixture layout. The test removes Playwright's default hide-scrollbars flag and verifies a nonzero classic gutter and narrow grid gutter rather than assuming the launch flag works. 195×422, 320×844, 390×844 and 1440×900; empty and eight-image history, Auto-VGL advertised and absent, Edit, prompt-ready Generate, recent disclosure and advanced negative/manual VGL. No generation calls. 195 CSS px is a stress viewport, **not a substitute for true 200% browser zoom**.

Measure document width and every visible layout box within the production shell, excluding hidden/inert/closed disclosure/sr-only content, inline/SVG without client width, and intentional intrinsic native single-line input/select value scrolling. Range controls additionally check actual box containment because their scrollWidth need not expose the protrusion. This is scoped horizontal geometry, not a general WCAG, visual, focus, motion, scrollbar reachability or mask interaction certification.
