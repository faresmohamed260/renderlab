**Binding UI-019:** skeleton means “data/media not loaded”; never implies queued/running progress, a fabricated percent, guaranteed ETA, an accepted request or a persisted result. Keep prompt, references/settings and recoverable errors; show explicit verified capabilities and server/job state. For bytes transferred, use measured byte events only, then distinct verification/persisting state. Unknown duration is indeterminate, not fake progress. Stable aria-busy region with concise status, inert/nonfocusable decorative placeholders, reduced-motion static equivalence; don't announce every tile or animation frame. Preserve focus and old confirmed content during refresh when safe for the same owner/query; never show stale private data on account/permission changes.
