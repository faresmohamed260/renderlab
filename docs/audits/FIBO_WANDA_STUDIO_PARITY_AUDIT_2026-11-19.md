## Decision: port the working Studio, do not recreate it

The user confirmed that the WANDA FIBO Studio already runs text-to-image, edits, masks, generated/manual VGL, inspiration and batches. **Do not treat failed experiments with alternate generic ComfyUI nodes as failures of WANDA Studio**. RenderLab must integrate the reference engine's proven semantics into its existing *owner-scoped, server-owned* job/storage framework. Keep the working FIBO Edit Turbo weights; do not introduce FIBO Dev, external Gemini/Qwen APIs, another model/provider, a local relay in production, or a second competing workflow.

Use this file to hand off the verified functional reference. `docs/architecture/FIBO_PRODUCTION_ROLLOUT_CONTRACT.md` remains normative; this audit records checked evidence and differences, and does not independently authorize production execution.

## Provenance and authorization gates

1. **Open-source schema package:** `bria-vgl` 0.10.2 ships MIT license and a preserved Bria copyright notice. The upstream GitHub/PyPI projects identify the package as MIT. Reuse an exact pinned release with its notices; do not copy the WANDA `vgl_vendor` folder indiscriminately.
2. **WANDA-specific adapter source:** The local `fibo_vgl/__init__.py` is installed with no adjacent license or Git provenance. It is a valuable executable specification, but do not silently copy an unverified private wrapper to the published production worker. Resolve source ownership/reuse permission, or implement an original thin adapter **against the same MIT `bria-vgl` API and public Qwen3-VL image-tokenizer interface**, not a different VGL generator.
3. **Weights:** Bria FIBO 2.0 Edit Turbo weights distributed through Comfy-Org are under **CC BY-NC 4.0**, independently of the MIT wrapper and `bria-vgl` package. Commercial serving requires separate Bria rights. The accepted project scope remains owner-controlled invite-only noncommercial until rights are documented.
4. **Runtime:** Repo is primary authority for RenderLab code. WANDA Studio is the *functional reference*, not a production credential store, persistence substrate, direct public web service or proof of hosted Modal readiness. Production deployment/worker mutation needs separate owner authorization and a rollback/qualification record.
