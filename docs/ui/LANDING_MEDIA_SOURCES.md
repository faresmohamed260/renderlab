# Landing Production Media Sources

**Status:** Production implementation provenance  
**Verified:** 2026-09-11  
**Applies to:** the curated media used by the approved public Landing implementation

## Purpose
The approved Landing composition was developed with temporary R&D photography. Production implementation must not silently inherit prototype media whose use has not been reviewed.

The current Landing uses the six Unsplash images below as a deliberately reviewed production media set. Each source page identifies the image as free to use under the Unsplash License. The selected set was also visually reviewed to avoid intentionally identifiable people, visible brand marks, or logo-dependent subject matter.

This is a static curated asset choice. RenderLab does not integrate the Unsplash API, expose Unsplash as a product capability, or claim ownership of these source photographs/renders.

## License boundary
Unsplash's published license/help guidance permits free commercial and non-commercial use without required attribution. That copyright license does not automatically clear every possible third-party right depicted in an image. RenderLab therefore deliberately avoids identifiable people and brand/logo-dependent imagery in this set.

License reference: https://unsplash.com/license

## Implementation rule
The exact photographs are not part of the RenderLab brand identity and may be replaced later with RenderLab-owned/generated media, but any replacement must preserve the accepted Landing composition, crop density, visual hierarchy and creative-state story and must have a documented right-to-use basis before production use.

Changing the imagery does not reopen the locked Lab Grid geometry. In particular, the lower-right Hero/Resolve media module continues to use the canonical quarter-circle / large-arc mask recorded in `LANDING_IMPLEMENTATION_CONTRACT.md`.
