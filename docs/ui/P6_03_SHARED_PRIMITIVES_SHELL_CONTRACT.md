## Goal and user value

One coherent dark-only Violet Studio glass language, maintained accessible controls and one consistent application shell so creative work feels immediate, uncluttered and navigable. Remove duplicate chrome/visual token owners only where proven safe; establish foundations before redesigning feature content. The user can always navigate, find account settings, and understand actionable job attention without learning provider internals.
