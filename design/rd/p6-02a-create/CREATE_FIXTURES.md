Capture: from the repository root, pinned dependencies and installed Chromium, run `node scripts/run-p602a-design-prototype.mjs --capture`. Preserves the previously qualified board smoke, then drives real isolated Chromium contexts, logs rendered contrast and layout measurements, records four viewport/preference videos and writes 32 settled composition PNGs (selector excluded from frame crop). 195 and 320 CSS px are additional stress checks with measured nonzero scrollbar gutter. Actual production shell and true browser zoom remain separate P6-02 implementation acceptance; do not claim that this neutral design shell fixes the runtime baseline. Evidence contains hashes and a source SHA, kept in ignored artifacts and uploaded privately in CI. No owner-path bundle yet; step 4 supplies that index and clip curation.

The branch-only push trigger on the existing optional isolation workflow permits real CI before opening a PR. No new protected check or deployment. It runs typecheck, offline production build and the existing bundle-exclusion gate, in addition to the isolated browser and fixture tests. The normal protected PR suite still applies after opening. Capture data are measured rendered CSS colors, not screenshot-pixel contrast or a complete accessibility audit. Artwork overlays, UA-native slider internals, true zoom, full IME and full production shell integration are not claimed by these checks.

Failure diagnostics: each state/width/preference is attempted separately; each failed sample keeps its screenshot and Playwright trace, with structured expected/actual, step, assertion/call log, and console errors in summary.json. A fresh navigation between samples prevents one failed gesture or overlay from poisoning later cases. Geometry and contrast run independently. Partial frames and four recordings where available are retained even on failure. The job exits nonzero for any sample, infrastructure, isolation or completeness failure. Typecheck and offline production build/exclusion run independently after dependency installation, and artifact upload runs even on failure. No threshold, width, or required state is waived.
