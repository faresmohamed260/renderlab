## Approved visual grammar
Preserve the selected Lab Matrix structure while materially raising the media layer:

- dominant photographic/generated visual work rather than abstract placeholder geometry;
- four media cells that keep the locked modular-R proportion logic;
- each cell expresses a different creative-state idea: Create, Shape with references, Set in motion, Keep and continue;
- bright authored media against restrained dark application chrome;
- precise sans-serif typography;
- depth comes from the media objects, framing, light and temporal behavior rather than generic glow decoration;
- motion happens inside and between media cells, plus bounded pointer depth, rather than generic fade-and-slide page entrances;
- mobile receives deliberate art direction rather than a scaled desktop composition;
- reduced motion resolves to a complete static state.
